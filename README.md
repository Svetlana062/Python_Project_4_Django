# Проект 4. Сервис управления рассылками
Чтобы удержать текущих клиентов бизнеса, часто используются вспомогательные, 
или «прогревающие», рассылки для информирования и привлечения.

В этом проекте разработан сервис управления рассылками, администрирования и 
получения статистики.
Курсовая работа состоит из двух частей:
* «Разработка сервиса» - в первой части проекта создана структура, 
реализован интерфейс шаблонов, выполнена настройка моделей и созданы 
CRUD-операции.
* «Расширение функционала» - во второй части расширена 
функциональность на основе уже написанного кода и собранного интерфейса,
добавлены формы, аутентификация, права доступа и кеширование.
